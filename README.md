# SUMNAY MEDIA Portfolio

A premium, high-converting portfolio designed for a bold digital agency. Features a custom liquid-glass and claymorphism design system, seamless light/dark mode toggling, and interactive project showcases.

## Live Demo
🚀 **[View the Live Portfolio Here](https://portfolio-for-ads.vercel.app/)**

## Technologies Used
- React (Vite)
- Tailwind CSS v4 (with custom CSS variables for advanced themes)
- Lucide React (Icons)
- React Router (Client-side routing)

## Features
- **Apple HIG-Inspired Light Theme:** Crisp, high-contrast light mode with tactile drop-shadows.
- **Deep Slate Dark Theme:** Immersive, high-contrast dark mode.
- **Glassmorphism & Claymorphism:** Custom `.glass-panel` and `.clay-panel` utilities with dynamic backdrop blurs and extruded shadows.
- **Staggered Grid Gallery:** Editorial-style CSS grid for showcasing graphic design work.
- **Interactive Lightbox:** Seamless image viewing experience without leaving the page.

## Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment
This project is configured for Vercel deployment with client-side routing support via `vercel.json`.
